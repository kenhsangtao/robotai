Hướng dẫn sử dụngSetup & usage guide

1. Nạp firmware1. Flash firmware

Dùng nút Nạp firmware ở đầu trang trên Chrome/Edge máy tính, hoặc tải firmware.bin. File đã gộp và nạp tại 0x0.

Use the Install firmware button in desktop Chrome/Edge, or download firmware.bin. It is a merged image flashed at 0x0.

2. Đấu pack Makita2. Connect the Makita pack

Dùng đầu Expansion Pins: DATA → GPIO2, ENABLE → GPIO3, B- → GND. Điện trở 4.7kΩ kéo DATA lên 3.3V.

Use the Expansion Pins header: DATA → GPIO2, ENABLE → GPIO3, B- → GND. Pull DATA up to 3.3V with 4.7kΩ.

3. Dùng màn cảm ứng3. Touchscreen

Các nút chính: XÓA LỖI, MỞ KHÓA, LED, ĐỌC PIN. Có nút đổi VN/EN.

Main buttons: CLEAR ERROR, UNLOCK, LED, READ. VI/EN language toggle is available.

4. Điều khiển qua Wi-Fi4. Wi-Fi control

Kết nối KST-MAKITA-TOOL, mật khẩu makita1234, sau đó mở 192.168.4.1.

Connect to KST-MAKITA-TOOL, password makita1234, then open 192.168.4.1.

5. Ngủ sâu5. Deep sleep

Giữ nút BOOT khoảng 2 giây để tắt màn hình/Wi-Fi và tiết kiệm pin. Bấm BOOT lần nữa để khởi động.

Hold BOOT for about 2 seconds to turn off the screen/Wi-Fi and save power. Press BOOT again to restart.

⚠️ An toàn⚠️ Safety

Điện trở kéo lên DATA chỉ được nối 3.3V; tuyệt đối không nối 5V hoặc B+/B-. GPIO ESP32 không chịu được 5V.

The DATA pull-up must connect to 3.3V only; never connect it to 5V or B+/B-. ESP32 GPIOs are not 5V-tolerant.
